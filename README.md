# Countdn

A modern countdown timer dashboard to keep track of your services that are currently on cooldown. Create and manage multiple countdowns with drag-and-drop functionality. Features a clean dark/light theme and preset durations for quick setup.

## Features

- Multiple countdown lists with drag-and-drop organization
- Preset duration options for fast timer creation
- Local storage persistence
- Dark/light theme toggle
- Responsive design with smooth animations

## Getting Started

```bash
pnpm install
pnpm dev
```
